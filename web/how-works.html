1. Input match video

Start from a full match recording.

2. DSP whistle detection + CNN filtering

Audio produces whistle candidates, then CNN filtering removes many false positives.

3. Intervals between whistles

Each whistle-to-whistle segment becomes a candidate rally interval.

4. Play / Not Play model

Frames inside one interval are scored, producing an interval probability array.

5. HITL review

Only ambiguous intervals are reviewed manually.

6. Clip generation

Final rallies are cut into individual clips.

7. Landing extraction

The last part of each rally is analyzed to estimate the landing point.

8. Final heatmap

All landings are aggregated into the final dashboard heatmap.
